# Third-party assets

The “Why Choose Redragon” section reproduces the four service benefit headings,
descriptions, and layout of https://redragonshop.com/ as requested. Its SVG icons
are theme-native drawings inspired by the reference. Benefit content and icons
can be changed through the theme editor.

Swiper 14.4.0 is vendored from the official npm package as
`assets/swiper-bundle.min.js` and `assets/swiper-bundle.min.css`.
Its MIT license is retained in `assets/swiper-LICENSE.txt` and the upstream headers.
Source: https://www.npmjs.com/package/swiper/v/14.4.0

The six `assets/hero-*.webp` files are desktop and mobile example banners from
https://redragonshop.com/, the reference site requested for this implementation.
They retain the original Redragon artwork and promotional copy. Merchants can
replace them through the slideshow's desktop and mobile image settings.

The eighteen `assets/top-picks-*.webp` images are 640px WebP examples from the
same reference store's “Top Picks For You” module, captured on 2026-11-10.
Product names, example USD prices, and review figures in `top-picks-card.liquid`
are a snapshot of that reference, not the merchant's catalog. Example buttons
open the matching reference product. Selecting a collection or products in the
theme editor replaces the examples with the merchant's catalog and cart forms.
Promotional text is editable and does not create a Shopify discount.
